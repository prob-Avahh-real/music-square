# AGENTS.md — Music Square

音悦广场。Node.js 后端 + iOS 前端。

## 命令
```bash
make install      # cd backend && npm install
make test         # cd backend && npm test
make backend      # cd backend && npm run dev
make ios          # open ios/*.xcodeproj
```

## 技术栈
后端: Node.js / Express / SQLite
前端: iOS (Swift)
